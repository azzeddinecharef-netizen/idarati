# IDARATI Company — Landing Page

صفحة هبوط تعريفية لشركة IDARATI، تدعم العربية والفرنسية.

## الملفات

- `index.html`: الصفحة الرئيسية (HTML/CSS/JavaScript).
- `idarati-video.mp4`: الفيديو التعريفي.
- `avis-client.mp3`: التسجيل الصوتي لرأي أحد العملاء.
- `google-apps-script.gs`: كود Google Apps Script لاستقبال بيانات الاستمارة في Google Sheets.
- `دليل-التثبيت.txt`: تعليمات الإعداد الأصلية.

## التشغيل

يمكن معاينة الموقع بفتح `index.html` في المتصفح. لنقل المشروع إلى استضافة ثابتة مثل GitHub Pages، يجب وضع الملفات في جذر المستودع والمحافظة على المسارات النسبية للفيديو والصوت.

## الإعدادات

عدّل متغيرات `window.CONFIG` قرب بداية `index.html` عند الحاجة. رابط `SHEET_URL` فارغ افتراضيًا؛ لن يعمل إرسال الاستمارة إلى Google Sheets قبل إعداد Google Apps Script ونشره وفق التعليمات الموجودة في دليل التثبيت. احذر من إضافة مفاتيح سرية أو كلمات مرور أو بيانات غير مخصصة للنشر إلى مستودع عام.

## الخصوصية

الملفات المرفقة تتضمن بيانات اتصال خاصة بالنشاط التجاري، ويمكن لزوار الموقع رؤيتها. يُنصح ببقاء المستودع خاصًا حتى مراجعة المحتوى والموافقة على إتاحته للعامة.
