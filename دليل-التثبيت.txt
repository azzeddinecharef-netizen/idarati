IDARATI : دليل تشغيل صفحة الهبوط (3 خطوات)
=============================================

محتوى المجلد:
  index.html              ← الصفحة كاملة (الصور والشعار مدمجة داخلها)
  avis-client.mp3         ← التسجيل الصوتي لرأي الزبون (مضغوط إلى 800 كيلوبايت)
  idarati-video.mp4       ← فيديو الصفحة (2.8 ميغا، مضغوط للويب). ضعه بجانب index.html
  google-apps-script.gs   ← كود ربط الاستمارة بـ Google Sheets

كل الإعدادات موجودة في أعلى ملف index.html داخل قسم:  window.CONFIG = { ... }
افتح الملف بأي محرر نصوص (Notepad / VS Code) وعدّل الأسطر فقط.

-------------------------------------------------
1) ربط الاستمارة بـ Google Sheets
-------------------------------------------------
  أ. أنشئ Google Sheet جديد (مثلاً "طلبات IDARATI").
  ب. Extensions ← Apps Script ← امسح الكود وألصق محتوى google-apps-script.gs ← Save.
  ج. Deploy ← New deployment ← اضغط على ⚙ واختر Web app
       Execute as: Me
       Who has access: Anyone
     ← Deploy ← وافق على الأذونات (Advanced ← Go to... إذا ظهر تحذير).
  د. انسخ "Web app URL" (ينتهي بـ /exec) وألصقه هنا في index.html:
       SHEET_URL: "https://script.google.com/macros/s/.../exec",
  هـ. جرّب الاستمارة: يظهر سطر جديد في ورقة "Demandes" خلال ثوانٍ.
     عمود "Statut" فيه قائمة (Nouveau / Appelé / Rappeler / Client...) لمتابعة الزبائن.
  (اختياري) لاستقبال إيميل مع كل طلب: ضع بريدك في NOTIFY_EMAIL داخل كود Apps Script ثم
     Deploy ← Manage deployments ← Edit ← Version: New version.

-------------------------------------------------
2) Facebook Pixel
-------------------------------------------------
  ألصق رقم البيكسل فقط (أرقام) في:
       FB_PIXEL_ID: "123456789012345",
  الأحداث التي تُرسل تلقائياً:
       PageView   ← عند فتح الصفحة
       Lead       ← عند إرسال الاستمارة بنجاح (هذا الحدث الذي تختاره كهدف في الحملة)
       Contact    ← عند الضغط على أي زر واتساب
       FormStart  ← (مخصص) عند بداية ملء الاستمارة
       VideoPlay  ← (مخصص) عند تشغيل الفيديو
       AudioPlay  ← (مخصص) عند تشغيل رأي الزبون
  للتحقق: ثبّت إضافة "Meta Pixel Helper" على Chrome وافتح صفحتك.
  روابط الإعلانات: أضف ?utm_source=facebook&utm_campaign=اسم_الحملة لرابط الصفحة،
  وستظهر المصدر في عمود "Source (UTM)" في الجدول.

-------------------------------------------------
3) الرفع على الاستضافة
-------------------------------------------------
  ارفع index.html و idarati-video.mp4 و avis-client.mp3 في نفس المجلد (public_html مثلاً).
  لصفحة بالعربية مباشرة:  votre-site.dz/          (العربية افتراضياً)
  لصفحة بالفرنسية مباشرة: votre-site.dz/?lang=fr   (مفيد لإعلانات موجهة بالفرنسية)

-------------------------------------------------
إعدادات أخرى في CONFIG
-------------------------------------------------
  WHATSAPP   رقم الواتساب بدون + (حالياً 213770345869 من Linktree)
  PHONE      رقم الهاتف (حالياً 0773 34 58 16 من الموقع والفيديو)
  EMAIL      البريد المعروض في أسفل الصفحة
  VIDEO_URL  اسم/رابط الفيديو. اتركه "" لإخفاء قسم الفيديو
  AUDIO_URL  ملف رأي الزبون (حالياً avis-client.mp3). النص تحت العنوان في AUDIO_NAME_AR / AUDIO_NAME_FR
